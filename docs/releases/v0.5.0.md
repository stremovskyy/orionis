# Orionis v0.5.0

The standalone auth server can load its JSON configuration from AWS AppConfig
through Confucius v1.4.1. Start it with `-config aws` and set `AWS_REGION`,
`AWS_APPCONFIG_APPLICATION`, `AWS_APPCONFIG_ENVIRONMENT`, and
`AWS_APPCONFIG_PROFILE` on the ECS task.

- Configuration is fetched once at startup, with a 30-second deadline and no
  fallback to an outdated local or Secrets Manager configuration.
- Signing keys continue to use Secrets Manager injection through
  `ORIONIS_SIGNING_KEY_PEM`; AppConfig contains only the environment reference.
- Existing local JSON files, configuration presence/default semantics, Go SDK
  APIs, OAuth responses, token claims, issuer, audiences, and scopes are preserved.
- AppConfig failures stop startup and redact provider, decoder, and validation
  values from the error. Running tasks are unaffected by a failed replacement.
- ECS templates now use AppConfig directly. Use rolling deployment with
  `minimumHealthyPercent=100` and `maximumPercent=200`, preserving the signing
  key and client configuration throughout migration.

Images: `stremovskyy/orionis:0.5.0` and `ghcr.io/stremovskyy/orionis:0.5.0`.

The release image and verification use patched Go 1.26.10, with patched
`golang.org/x/net` and `golang.org/x/crypto` dependencies. The patched dependencies require Go 1.26, so the module minimum is now
Go 1.26.0.

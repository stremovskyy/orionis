# Orionis v0.6.0

The standalone auth server now accepts JSON and YAML configuration for both local
files and AWS AppConfig. The format is detected from the content, regardless of
filename, extension, or AppConfig content type. No format flag or environment
variable is required.

- YAML uses the existing JSON field names, schema, defaults, and runtime
  validation, including duration strings and signing-key environment references.
- Configuration must contain exactly one document. Date-like YAML scalars retain
  their literal text, including client IDs and credentials.
- Local JSON configuration, public Go APIs, OAuth responses, token claims, and
  endpoint paths remain compatible.
- AWS AppConfig is still fetched once at startup with a 30-second deadline.
  Deploy the configuration before rolling ECS task replacement.
- Go requirements are unchanged: module minimum Go 1.26.0 and build/verification
  toolchain Go 1.26.10.

Existing startup commands continue to work. To use the YAML example locally:

```bash
go run ./cmd/orionis-auth -config ./config/orionis.example.yaml
```

Upgrade the Go module with `go get github.com/stremovskyy/orionis@v0.6.0`.

Images: `stremovskyy/orionis:0.6.0` and `ghcr.io/stremovskyy/orionis:0.6.0`.

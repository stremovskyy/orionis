What Orionis gives you

  • Readable chain-first builders for clients, resource guards, and auth-server routes.
  • Ed25519 JWT signing by default with signer interfaces for KMS, Vault, HSM, or other algorithms.
  • Local JWT validation in resource services through JWKS, without per-request auth-server calls.
  • Docker Hub, GitHub Packages, and AWS ECS templates for simple deployment.
